### 📦 Spotlight: UrduKit NLP Middleware

[![PyPI version](https://img.shields.io/pypi/v/urdukit.svg?style=flat-square&color=0ea5e9)](https://pypi.org/project/urdukit/)
[![Downloads](https://static.pepy.tech/badge/urdukit)](https://pepy.tech/project/urdukit)

```bash
pip install urdukit
```

```python
import urdukit as uk

# Normalize Roman Urdu text
normalized = uk.normalize("ye boht zabardast kaam hai")
print(normalized)  # "yeh bohat zabardast kaam hai"

# Detect script (Urdu / Roman Urdu / English)
print(uk.detect_script("بہت شکریہ"))  # "urdu_arabic"
```
